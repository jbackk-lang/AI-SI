# Rozmiar lokalnego TSI — 22 października 2026

Pomiar obejmuje pliki z kodem. Pominięto historię Git oraz cache Pythona i pytest. MB = 1 000 000 B. Nie jest to RAM ani rozmiar ZIP.

| Składnik | Bajty | MB |
|---|---:|---:|

| Współdzielony silnik i validator z kodem | 1,874,684,120 | 1874,68 |
| Aktualne środowisko bibliotek Python | 1,296,023,630 | 1296,02 |
| Bazowa instalacja Python | 677,806,351 | 677,81 |
| Suma konserwatywnego budżetu pełnego środowiska | 5,466,693,921 | 5466,69 |

To budżet przed zbudowaniem portable: obejmuje także materiały robocze i biblioteki potencjalnie zbędne. Przenośny interpreter, ścieżki względne i uruchomienie na czystym komputerze wymagają osobnego przygotowania. Nie wydano nowej paczki ZIP. Pakiet do udostępnienia powinien mieć pustą historię i nie zawierać dokumentów użytkownika.

Aplikacja bez treningów, kopii, runtime i testów zajmuje 254,44 MB. Pakiet pętli nauki zajmuje 46,84 MB i nie zawiera interpretera ani bibliotek. Pętla potrzebuje lokalnego środowiska PyTorch. Kolejne źródła, zapisy wag i logi zwiększają rozmiar podczas pracy.
